# 踩坑

| 现象 | 根因 | 正确做法 |
|---|---|---|
| 刷新编辑页还保留改动 | PDD 会保留编辑草稿 | 关闭旧编辑标签，再从商品列表重新点「编辑」 |
| 填 72 SKU 超时 | `page.evaluate` 15s 上限 | 用 CDP `Runtime.evaluate`，timeout 240s |
| 只填了十几行 | 虚拟滚动只渲染可见行 | 滚完所有容器 + window |
| 提交后价格/库存没变 | 点成了顶部/保存草稿 | 点底部「提交」，检查 success URL |
| 库存总数差 1 | 个别 SKU 未填/重复 code | 回读页面总库存，按 SKU 补 |
| 线上恢复不精确 | 只靠百分比反推 | 存原值清单，按 code 回填 |
| 同一商品重复操作 | 重复跑 fill 叠加百分比 | 一次只跑一个动作，先核对原值 |
